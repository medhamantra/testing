System Settings

Enter the deployed Google Apps Script Web App URL to sync payments to Google Sheets. Leave empty to use the default URL from the code.

How to set up Google Sheets integration:

  1. Create a Google Sheet with column headers (see code comments for exact columns).
  2. Open Extensions → Apps Script in the Google Sheet.
  3. Paste the doPost function (see code comments for reference).
  4. Deploy → New Deployment → Web App. Execute as: Me. Access: Anyone.
  5. Copy the Web App URL and paste it above, then click Save Settings.
⚠ Configuration Required: Google Apps Script URL is not configured. Payment data cannot be synced to Google Sheets until the Web App URL is added.
